Oklab Color Space Pickers (Fork)

A focused exploration of Oklab-derived color spaces: OKHSV, OKLCH, and three views of OKHSL.

This is a simplified fork of Björn Ottosson's excellent interactive color picker comparison, created in collaboration with an LLM to focus only on the Oklab family of color spaces. It deletes color pickers from that: HSV, HSL, and HSLuv.

Source code available on GitHub: earthbound19/oklab-pickers. The original which this is forked from is here.
